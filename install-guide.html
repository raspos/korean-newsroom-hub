    이름은 KOREAN NEWSROOM. 운영자가 준 HTTPS /mcp 주소 또는 비공개 Tunnel 안내를 따릅니다. HUB 주소는 서버 주소가 아닙니다.

    운영자가 지정한 인증 방식을 선택합니다. 관련 채팅·메모리가 앱에 전달될 수 있다는 안내를 확인합니다. 기관 키나 서버 토큰을 질문창에 붙여넣지 않습니다.
  4. 생성 후 연결
    ‘플러그인으로 생성’ → ‘KOREAN NEWSROOM 연결’. 설치된 플러그인 상세에서 ‘채팅에서 사용해 보기’를 선택합니다.

    2025년 12월 저축성수신금리가 전월보다 0.09%p 올랐다는 게 맞아? KOREAN NEWSROOM 도구로 조회하고 두 달의 수치·단위·기준월·통계표 ID·공식 출처와 계산식을 보여줘.
    도구 호출과 공식 출처를 확인합니다. 일반 답변만 나오면 연결 성공으로 판단하지 않습니다.
