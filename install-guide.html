    이름: KOREAN NEWSROOM HTTPS
    서버 URL: https://korean-newsroom-mcp.onrender.com/mcp
    인증: OAuth. 자동 감지된 설정을 사용합니다. 클라이언트 시크릿·기관 키는 입력하지 않습니다.
  3. 생성 → 연결 → 이용자 로그인
    채팅·활성 메모리 공유 안내를 읽고 동의한 뒤 생성·연결합니다. 로그인 창에서 처음이면 Sign up으로 이메일·서비스용 새 비밀번호를 등록합니다. 관리자·ChatGPT 로그인과 별개입니다.
  4. 운영자 접근 승인 → 도구 새로 고침
    가입 이메일을 운영자에게 알려 접근 승인을 받습니다. 이후 설정 → 플러그인 → KOREAN NEWSROOM HTTPS → 도구 새로 고침. 비밀번호·인증 코드는 보내지 않습니다.
  5. 새 대화에서 첫 질문
    플러그인 상세 → 채팅에서 사용해 보기.
    2025년 12월 저축성수신금리가 전월보다 0.09%p 올랐다는 게 맞아? ECOS 공식 API 도구로 조회하고 수치·단위·기준월·통계표 ID·출처와 계산식을 보여줘.
